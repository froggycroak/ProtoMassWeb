安装指南

建筑原型手册客户端 · 示例步骤（后续与正式安装稿对齐）

1. 内网连通

  1. 【连通测试】打开门户首页：/（能打开即表示可达 AppServer）。
  2. 【若无法访问】设备可能不在华建集团内网，请先按 远程办公 连接 VPN 后再试。
  3. 【若访问成功】继续下一步。

2. 环境要求

  • 操作系统：Windows 10/11
  • 建模软件：Rhino 8（当前安装包载荷为 rhino81-net7）
  • 网络：集团内网，或 VPN 后可达本门户所在主机

占位图 · 建议换成 Rhino 8 启动或安装向导截图

3. 下载并运行安装向导

  1. 前往 下载中心 获取客户端安装包 zip。
  2. 解压后运行 install.ps1（建议：powershell -sta -File .\install.ps1）。
  3. 向导会将插件写入 %AppData%\ArchiFrog\ProtoMass.Client\。
  4. 在向导中粘贴你的 ApiKey（勿直接覆盖样例 credentials 文件）。

4. 配置 AppServerUrl

  • 客户端开发者配置中的服务入口应指向本门户基址（无路径后缀），例如：http://10.253.6.206:7250。
  • 可用工作台命令 developer 打开配置对话框核对。

5. 启动软件

  1. 打开 Rhinoceros 8。

快速上手

工作台常用操作提纲（示例，后续完善截图与步骤）

开始前

  • 已按 安装指南 完成客户端安装。
  • 已用 setapikey（或安装向导）写入本机 ApiKey。
  • AppServerUrl 指向门户基址（如 http://10.253.6.206:7250）。

工作台命令（节选）

中央视口下方指令框输入后按 Enter；命令不区分大小写。

命令作用
generate触发生成体量（等同左侧面板按钮）
developer打开工作台配置 · 开发者选项
protoconfig打开工作台配置 · 原型预加载
setapikey设置 API Key（只写不读）
readapikey在打印区显示当前 Key

完整列表见仓库 docs/guide-cmd.md。

推荐流程（示例）

  1. 确认网络：能打开 门户首页。
  2. setapikey 写入密钥（若安装时未填）。
  3. developer 核对 AppServerUrl / 单入口模式。
  4. 在左侧面板选择原型并 generate。

远程办公

不在集团内网时，须先连接集团 VPN

为何需要 VPN

ProtoMass AppServer 部署在集团内网（样例主机 10.253.6.206:7250）。外网或家用网络无法直连时，需通过集团 SSL-VPN 进入内网，再访问门户与业务接口。

连接步骤（提纲）

  1. 打开集团 VPN 入口：https://180.166.157.216（EasyConnect SSL-VPN）。
  2. 按账号权限登录并完成客户端连接。
  3. 浏览器访问 本门户首页，确认页面可打开。
  4. 再启动 Rhino / ProtoMass 客户端进行设计操作。

打开 VPN 入口 下载 VPN 说明 PDF

正式 PDF 手册放入服务器 DownloadsRoot/docs/ 后，下载中心链接才会可用。

仍无法访问时

  • 确认 VPN 已连接成功（非仅打开登录页）。
  • 确认门户地址与安装指南一致（端口 7250）。
  • 联系项目运维核对白名单 / 主机状态（勿向终端用户分发运维 URL）。
