产品简介

建筑原型手册-智能设计工具的定位、背景与适用对象

产品定位

建筑原型手册-智能设计工具是一款面向原创设计的，基于案例与原型的，建筑体量方案智能演绎工具，由华建集团中央研究院与华东院合作研发。该工具提供嵌入Rhino软件的全屏工作台，帮助建筑师在方案前期快速生成、比选符合场地条件与规划指标的体量方案。它将建筑师长期实践中形成的「原型」工作方法数字化：从既有案例提炼可复用的形式特征与操作规则，在新场地环境中演绎组合，穷举并迭代选优。

项目背景

建筑原创设计要求建筑师解构重组经验知识、快速提出大量方案，并在充分考虑场地条件的基础上迭代选优。华东院创作中心基于多年实践，发展出一套「原型」方法：通过几何形态分析形成建筑体量原型，再基于场地条件演绎原型，从而系统探索初步方案。数字化与人工智能技术为这一方法带来新机遇——原型可进一步抽象提炼、组合成更多新颖体量；计算可快速大量执行，提升方案试排与选优的规模与速度。本工具即在此背景下，服务原创设计方案试排体制增效。

适用对象

  • 建筑方案创作、城市设计相关业务团队。
  • 相关科研究人员、开发者、教师及学生。

客户端使用

在客户端中加载场地、设置参数、生成体量等核心流程

开始前

  • 已按 客户端安装 完成客户端安装，并能打开本门户。
  • 已用安装向导或命令 setapikey 写入本机 ApiKey。
  • 在 Rhino 8 中打开或新建文档，启动 ProtoMass 全屏工作台。

工作台界面分左右两区：左侧为功能参数面板（场地模型、体量生成等），右侧为三维预览视口。一次完整比选通常按「加载场地 → 拾取红线/控制线 → 配置规范参数 → 生成体量 → 拷贝到 Rhino」进行。

客户端启动界面示意

若文档长度单位不是米，可先在「高级设置」中将长度单位设为「自动（跟随 Rhino 文档）」，再开展拾取与生成，避免数值换算偏差。

场地环境加载

在左侧「场地模型」区选择加载方式并填写参数后，系统在视口显示周边建筑与道路轮廓，为体量放置提供参照。支持三种方式：

  • 本地文件：选择本机场地数据文件，直接加载至视口预览（适用于已有场地模型）。
  • 城市与地点名称：填写城市、地点，经开放地图数据拉取周边建成环境（适合快速了解陌生地块）。
  • 经纬度坐标：输入经度、纬度，按坐标获取周边建筑与道路轮廓（适用于已知精确坐标）。

从网络数据加载场地模型

加载过程中视口中央会显示等待提示；完成后几何以预览形式叠加。对结果不满意时可更换方式重新获取。满意后可用「拷贝到 Rhino」将场地写入当前文档。

红线与控制线

在「体量生成」模块中完成场地红线与建筑控制线拾取，二者是后续生成的空间边界依据。

  • 场地红线：点击「拾取」，在 Rhino 视图中选择代表用地边界的闭合曲线。
  • 建筑控制线：可再次「拾取」已有控制线，用户可根据实际设计需求在红线区域内任意绘制；或在已有红线后点击「生成」，由系统按退让距离向内偏移自动生成（适合快速方案阶段）。

体量生成操作面板示意

设计参数

完成边界绑定后，在体量生成面板配置规范与原型参数：

  • 建筑密度 / 覆盖面积；与双向联动，改其一，另一项实时换算。
  • 容积率 / 建筑面积；与双向联动，改其一，另一项实时换算。
  • 高度限制：最大允许高度，默认 24 m。过低可能导致无法满足容积率。
  • 朝向：可拾取积极朝向与消极朝向向量。
  • 原型模式：
    模式 说明
    单一要素 单一体量造型构成整个方案
    组合要素 一系列相近体量的组合共同构成方案
    组合要素- 一系列相近体量的组合共同构成方案，每一体量的造型不可选
    组合要素+ 一系列相近体量的组合共同构成方案，增加一个特殊体量

生成体量、预览、拷贝到Rhino

  • 点击「生成体量」（或在指令框输入 generate），系统在满足红线、控制线与指标约束下计算并生成方案。
  • 右侧视口三维预览：右键拖动旋转，滚轮缩放，Shift + 右键平移。顶部工具栏可切换透视/正交、显示模式等。
  • 预览满意后，点击「拷贝到 Rhino」，将体量写入当前文档为可编辑几何，便于深化、立面与出图。
  • 不满意时可调整密度、容积率、限高、朝向或原型模式后再次生成，支持多轮迭代比选。

体量生成效果示意

注意：预览不会自动写入文档，须手动点击「拷贝到 Rhino」才会写入Rhino文件，类似grasshopper中的bake操作。

网页端使用

无需安装 Rhino，在浏览器中完成场地加载、体量生成、Mesh 预览与 3dm 下载。

  • 入口：/workbench/（产品入口「网页版」亦可进入）。
  • 鉴权：与 Rhino 客户端共用同一用户 ApiKey，在左侧「高级设置 → 开发者选项」中粘贴；勿放入 URL。
  • 流程：可选「地图选点」确定建模范围并加载 OSM → 绘制场地红线（视口 XOY 折线）→ 绘制或「生成」建筑控制线（默认内退 5m）→ 生成体量 → 三维预览 → 下载 3dm（结果约 60 分钟内有效，过期请重新生成）。
  • 浏览器要求：现代 Chromium / Edge / Firefox；需能访问本门户所在 AppServer。

网页端侧重试用与协作交付；专业落图、文档内拾取与 Bake 仍请使用 Rhino 插件。

远程办公

集团局域网外通过VPN接入集团内网，再使用应用客户端。操作步骤可以参考本教程或下载中心中的华建集团VPN用户手册（内容相同）。本教程中的操作流程只需操作一次，后续使用时只需一键启动VPN即可。
